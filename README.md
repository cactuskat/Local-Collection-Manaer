# Local-Collection-Manager
CPSC 3750 Solo Project 1

A Wine Collection Manager CRUD Project

File Location to Use: C:\xampp\htdocs\wine-inventory
Exact folder name to place inside XAMPP's htdocs: wine-inventory
Exact localhost URL to open: http://localhost/wine-inventory/
Folder should include: index.html,script.js, and style.css

Notes:
- Application runs on http://localhost
- XAMPP Apache must be running
- Data stored in javascript and persisted via localstorage
- application starts with 30 records
